rocket-chat 0.5.3 lists Ollama's cloud models and frees GPU memory when you switch models.

## Ollama cloud models in the model list ([#36](https://github.com/sgstreet/rocket-chat/pull/36))

- `/model` and `--list-models` list the ollama.com cloud models after your local models, marked
  `cloud`, under the names your Ollama server knows them by, such as `gpt-oss:120b-cloud` or
  `kimi-k3:cloud`. Tab completion includes them. The list comes from `https://ollama.com/api/tags`
  and is fetched once per session.
- A cloud model is used like any other (`/model kimi-k3:cloud`); your Ollama server passes the chat
  on to ollama.com. Run `ollama signin` once on that machine; rocket-chat says so if it is needed,
  and suggests updating Ollama when an older server does not know a cloud model.
- If ollama.com cannot be reached, your local models are listed with a note saying why.
- Set `backends.ollama.cloud_models` to `false` to list local models only.

## Switching model unloads the old one ([#37](https://github.com/sgstreet/rocket-chat/pull/37))

- `/model`, `/resume` of a chat with another model, and `/backend` unload the Ollama model the chat
  leaves, so only the model in use holds GPU memory. A notice says when a model is unloaded.
- A model the chat never sent a message to, a cloud model, and a model another running copy of
  rocket-chat uses are left loaded.
- Set `backends.ollama.unload_on_switch` to `false` to keep models loaded when switching.
