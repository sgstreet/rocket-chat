rocket-chat 0.5.2 frees Ollama's GPU memory when you quit, and gives the composer a clearer look.

## Ollama: memory freed on exit, servers shared between copies

- When rocket-chat exits, it unloads the models it chatted with from an Ollama server it did not
  start, such as the `ollama` system service. Before, Ollama kept the last model in GPU memory for
  `keep_alive` (5 minutes by default). Set `backends.ollama.unload_on_exit` to `false` to keep
  models loaded ([#33](https://github.com/sgstreet/rocket-chat/pull/33)).
- Copies of rocket-chat running at the same time share a server one of them started. It stops
  when the last copy using it exits, whichever copy started it, so quitting one chat no longer
  breaks another. It also stops if that copy crashes or its terminal is closed. A copy leaves
  loaded any model another copy has used, and a server rocket-chat did not start is never stopped
  ([#34](https://github.com/sgstreet/rocket-chat/pull/34)).
- On Windows a started server still stops with the copy that started it.

## Composer ([#32](https://github.com/sgstreet/rocket-chat/pull/32))

- A rule separates the conversation from the composer (status bar, input box and key hints).
- `/lines <n>` sets how many lines the input box shows, from 1 to 20 (default 3).
  `ui.input_lines` in the config file keeps the setting.
