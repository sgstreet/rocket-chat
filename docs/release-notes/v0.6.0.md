rocket-chat 0.6.0 adds a third backend: Z.ai, for the GLM models.

## Z.ai backend ([#39](https://github.com/sgstreet/rocket-chat/pull/39))

- Choose it with `-b zai`, `/backend zai` in a chat, or `"default_backend": "zai"`. The default
  model is `glm-5.3`; `rocket-chat -b zai --list-models` and `/model` list the others.
- Save an API key from https://z.ai/manage-apikey/apikey-list with `rocket-chat --set-key zai` or
  `/key zai`, or set `ZAI_API_KEY`. Starting a chat with Z.ai and no key asks for one.
- Works with pay-as-you-go keys and GLM Coding Plan subscriptions. With `backends.zai.endpoint` at
  its default, `auto`, rocket-chat moves to the Coding Plan endpoint when Z.ai says the key has no
  balance on the general one, and says so; set it to `coding` or `general` to skip that check.
- The model's reasoning streams as thinking (Ctrl+T to show it); `think` turns it on or off.
- Web search with Z.ai's own search tool: `--search` or `/search on`. Answers list the sources they
  cite and the ones only consulted. It is off by default because searches count against your plan;
  `search.engine`, `search.count` and `search.recency` tune it.
- Clear errors for a rejected key, no balance, an unknown model and rate limits.

New config files include a `zai` section. See the Z.ai section of the README for all settings.
