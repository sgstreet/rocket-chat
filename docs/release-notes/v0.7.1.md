rocket-chat 0.7.1 fixes Ollama replies with web search that showed the sources but no answer.

## Ollama search: the answer no longer goes missing ([#57](https://github.com/sgstreet/rocket-chat/pull/57))

- With web search on, a reply sometimes showed only the sources. This happened when the model read
  the search results and then stopped without answering (or answered only in its thinking), which
  is common with small and thinking models, or when it used up `max_rounds` of searching.
- Now, when a round after a search ends with no answer, rocket-chat asks the model once more, without
  tools, to answer from the results it found, with citations. The same happens when `max_rounds` is
  reached, instead of silently dropping the tools.
- This extra request is made at most once per reply, and never when the model did not search.

All changes: [v0.7.0...v0.7.1](https://github.com/sgstreet/rocket-chat/compare/v0.7.0...v0.7.1)
