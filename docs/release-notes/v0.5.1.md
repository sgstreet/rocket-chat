rocket-chat 0.5.1 starts every chat with a role and remembers the one you pick.

## Roles: a default, and your last choice remembered ([#28](https://github.com/sgstreet/rocket-chat/pull/28))

- Chats and one-shot answers start with the **General Assistant** when no role is configured, including
  existing config files with `"default_role": ""`. Set `"default_role": "off"` (or `"none"`) for no
  system prompt, or use `--role off` for a single run. New config files say
  `"default_role": "general"`.
- The role you choose with `/role` is remembered for later runs: a named role,
  `/role custom <text>` or `/role off`. It is kept in `~/.local/share/rocket-chat/state.json`.
- A run starts with `--role` or `-s` if given, otherwise the role you last chose, otherwise
  `default_role`. This applies to one-shot answers too, so scripts that need a fixed prompt should
  pass `--role` or `-s`. A resumed chat keeps the role it was saved with.
- `--list-roles` marks the role a run would start with.
