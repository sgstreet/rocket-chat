rocket-chat 0.7.0 shows how full the context window is, compacts long chats, and suggests follow-up questions.

## See how much of the context window a chat takes ([#44](https://github.com/sgstreet/rocket-chat/pull/44), [#46](https://github.com/sgstreet/rocket-chat/pull/46))

- `/context` shows the tokens the conversation takes out of the model's context window, the system
  prompt's share, the number of messages and the largest one. From 80% the status line shows
  `context NN%`.
- The count comes from the backend after each reply; before the first reply it is estimated from
  the text and marked `~`.
- The window comes from the backend: Gemini reports each model's limit; Ollama the context it runs
  the model with (known once the model is loaded, or `num_ctx`); Z.ai a built-in table
  (`glm-5.3` and `glm-5.3-flash`: 1,048,576 tokens, measured) or the new `context_window` setting.
- Ollama's default context is small, and when a chat outgrows it Ollama silently drops the start of
  the conversation. `/context` now says when this happens and suggests `/compact` or a larger
  `backends.ollama.num_ctx`.
- Z.ai's "Prompt exceeds max length" error now explains itself and suggests `/compact`.

## Compact long chats ([#45](https://github.com/sgstreet/rocket-chat/pull/45))

- `/compact [focus]` has the model summarize the older messages; from then on the summary is sent
  in their place, followed by the latest messages word for word (4 by default, `compact.keep`).
  `/compact keep the code and the decisions` says what to keep.
- The older messages stay on screen, marked `compacted`, and in `/export`. Saved chats keep the
  summary, so `/resume` carries on from it. Compacting again folds the earlier summary in, and Esc
  stops a compaction in progress.
- `compact.auto` (for example `0.85`, off by default) compacts automatically before sending once a
  chat takes that share of the window.
- A summary Gemini writes of answers grounded with Google Search is only sent to Gemini, like the
  answers themselves.

## Follow-up suggestions ([#47](https://github.com/sgstreet/rocket-chat/pull/47))

- Under each reply the chat suggests three follow-up questions. Alt+1, Alt+2 or Alt+3, or a click,
  puts one in the input box to edit or send.
- They come from a small second request to the same model once the reply is done, so they count as
  an extra request with providers that bill or limit by request. `ui.followup_models` can name a
  faster model per backend, for example `{"zai": "glm-5.3-flash"}`.
- On by default: `/followups off` turns them off for a chat, `"ui": {"followups": false}` for good.
