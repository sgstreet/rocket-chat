rocket-chat 0.6.1 remembers the backend and model you pick in a chat, and simplifies the mouse.

## The chat remembers your backend and model ([#42](https://github.com/sgstreet/rocket-chat/pull/42))

- The backend you choose with `/backend`, and for each backend the model you choose with `/model`,
  are remembered for the next chat, alongside the role (in `~/.local/share/rocket-chat/state.json`).
- A chat starts with `-b` and `-m` if given, otherwise the remembered backend and its model,
  otherwise `default_backend` and the backend's `model` setting. `-b` and `-m` apply to that run
  only and are not remembered.
- `/backend` switches to the model you last used on that backend. `/model default` goes back to the
  backend's default model.
- One-shot answers (`rocket-chat "question"`) ignore the remembered choices, so scripts do not
  change with what you pick in a chat.
- If the remembered backend cannot be opened, for example because its key was removed, the chat
  starts with `default_backend` and says why.

## Mouse: no more drag selection or Ctrl+V paste ([#41](https://github.com/sgstreet/rocket-chat/pull/41))

- Dragging to select text and pasting with Ctrl+V or the middle button are gone; they did not work
  well. Use your terminal's own selection (hold Shift, or Option on macOS) and its paste key, which
  go straight into the input box.
- The mouse wheel still scrolls, clicking still moves the focus or places the cursor, and clicking a
  link still opens it. `/copy` still copies a reply or a code block.
