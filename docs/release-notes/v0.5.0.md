rocket-chat 0.5.0 makes the interactive chat work like a modern terminal app: the mouse
scrolls, selects and opens links, inputs have history and Tab completion, Markdown rendering can
be turned off, and system prompts are managed with a single `/role` command.

## Changed: `/system` is replaced by `/role` ([#26](https://github.com/sgstreet/rocket-chat/pull/26))

`/system` and `/role` overlapped, so everything about the system prompt now goes through `/role`.
Typing `/system` tells you where its functions went.

| Before | Now |
|---|---|
| `/system` | `/role` shows the prompt in use, in full, and lists the roles |
| `/system <text>` | `/role custom <text>` |
| `/system clear` | `/role off` |
| | `/role show <name>` prints a role's prompt without switching to it |

On the command line nothing changes: `--role` and `-s "text"` work as before, and the new
`--show-role <name>` prints a role's prompt.

Other role changes:

- A `roles` entry in `config.json` that reuses a built-in ID (`general`, `technical`, `research`)
  now changes only what it sets. `"technical": {"search": true}` keeps the Technical Adviser prompt
  and turns web search on with it. Before, it replaced the whole role. ([#26](https://github.com/sgstreet/rocket-chat/pull/26))
- The General Assistant prompt no longer tells the model to use Markdown. ([#24](https://github.com/sgstreet/rocket-chat/pull/24))

## Mouse, copy and paste ([#19](https://github.com/sgstreet/rocket-chat/pull/19), [#20](https://github.com/sgstreet/rocket-chat/pull/20), [#21](https://github.com/sgstreet/rocket-chat/pull/21), [#22](https://github.com/sgstreet/rocket-chat/pull/22))

- The mouse wheel scrolls the conversation. ([#19](https://github.com/sgstreet/rocket-chat/pull/19))
- Drag over the conversation to select text; it is copied when you let go, through the terminal
  (OSC 52, which works over SSH) and the system clipboard (for terminals without OSC 52, such as
  GNOME Terminal). ([#20](https://github.com/sgstreet/rocket-chat/pull/20))
- Click a link to open it in your browser. Links are underlined: Markdown links, Gemini sources and
  URLs you typed. Only `http`, `https` and `mailto` links are opened; over SSH the link is copied. ([#20](https://github.com/sgstreet/rocket-chat/pull/20), [#22](https://github.com/sgstreet/rocket-chat/pull/22))
- Ctrl+V or the middle button pastes, from the system clipboard or the terminal's. ([#20](https://github.com/sgstreet/rocket-chat/pull/20))
- Click the conversation to scroll it with the arrow, page and Home/End keys; click the input box,
  press Esc or start typing to go back. Clicking in the input box moves the cursor there. ([#21](https://github.com/sgstreet/rocket-chat/pull/21))
- `"ui": {"mouse": false}` leaves the mouse to the terminal.

## Input history and Tab completion ([#19](https://github.com/sgstreet/rocket-chat/pull/19), [#23](https://github.com/sgstreet/rocket-chat/pull/23))

- Up and Down (or Ctrl+P and Ctrl+N) recall earlier messages and commands, from this and earlier
  chats. Recalled inputs can be edited before sending. History is kept in
  `~/.local/share/rocket-chat/history` (newest 1000 entries); `"ui": {"history": false}` keeps it
  for the current chat only. `/key` lines with a key in them are never recorded. ([#19](https://github.com/sgstreet/rocket-chat/pull/19))
- Tab completes commands and their arguments: backends, models, roles, and the options of
  `/search`, `/key`, `/markdown` and `/copy`. `/model <Tab>` fetches the model list itself. ([#19](https://github.com/sgstreet/rocket-chat/pull/19), [#23](https://github.com/sgstreet/rocket-chat/pull/23))

## Markdown ([#24](https://github.com/sgstreet/rocket-chat/pull/24))

- `/markdown off`, or `"ui": {"markdown": false}`, shows replies exactly as the model wrote them;
  `/markdown on` renders them again.
- `rocket-chat --render "question"` prints the one-shot answer as rendered Markdown, wrapped to the
  terminal and styled for its background, once it is complete.

## Fixes

- `/model` Tab completion works in a new chat, and after `/backend` or `/resume`, instead of
  finding nothing until `/model` had been run. ([#23](https://github.com/sgstreet/rocket-chat/pull/23))

## Upgrading

New settings appear in config files created from now on (`ui.mouse`, `ui.history`, `ui.markdown`);
existing files work unchanged and get the defaults.

Documentation: role fields and prompts kept in files are now described in the README ([#25](https://github.com/sgstreet/rocket-chat/pull/25)).
